# ZVV 连续对话表情包

把一句话变成一张张维为（ZVV）连续对话拼接图。

## 何时使用

- 用户给出一个观点、吐槽或立场，想要一张“张维为回应式”的表情包拼接图。
- 用户明确说“连续对话”“台词拼接”“拼接成一张图”。
- 用户要求把上下文里的某句话可视化。

## 素材库

- 素材目录：项目根目录的 `vv/`（可用 `ZVV_LIBRARY` 环境变量或 `--library` 覆盖）。
- 每张图**文件名就是它的台词含义**，例如 `我觉得这就是一种自信.png`。
- `空白*.png`、`万能模板*.png` 是空模板，默认不要使用。
- 单次拼接上限 **15 张**，超过就必须裁到 15 张以内。

## 工作流

### 1. 先用本地脚本拿候选，避免把 400+ 个文件名塞进上下文

```bash
python3 scripts/zvv_select.py "用户的句子" --top 24
```

脚本会用主题词典 + 字符二元组 + 关键词重叠打分，返回最相关的候选（含分数与命中理由）。
把用户句子当成“语义意图”，从候选里挑出能顺着说下来的 4～8 张（用户没指定就默认 6 张）。

### 2. 自己判断语义与顺序（这一步不要外包给脚本）

- 顺序要有节奏：第一句像开场（“我觉得…”“说实话…”），中间层层递进，最后落在最点题、最有梗的那句。
- 相邻两句尽量同一话题，读起来像同一个人连续发言。
- 台词默认照抄文件名，只有在明显更贴合用户语境时才做极轻微润色，**不能编造素材里没有的话**。

### 3. 渲染成 PNG

```bash
python3 scripts/zvv_stitch.py "用户的句子" \
  --files "我觉得这就是一种自信.png,这个盒饭确实比美国中产阶级吃的好.png" \
  --mode subtitle --out /tmp/zvv.png
```

- `--mode subtitle`：台词拼接，裁切画面中部 + 压字幕条（默认）。
- `--mode full`：整图竖向拼接。
- 不传 `--files` 时脚本会自己按本地打分挑素材，适合快速出图。
- 脚本优先调用已编译好的 App 二进制渲染（保证和 GUI 完全一致），没有 App 时回退 Pillow。

### 4. 交付

- 用 Markdown 图片语法把生成结果展示给用户：`![zvv](/绝对/路径/zvv.png)`。
- 附一句说明：用了哪几张素材、名字里的语义主题是什么。

## 写进缓存目录

App 的缓存目录（默认 `~/Library/Caches/ZVVQuest`）里保存的是“已生成”的作品；
用脚本出图时建议 `--out` 直接写到用户指定位置，需要归档时再指定缓存目录。
